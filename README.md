# birthday

דף הפתעה ליום הולדת, בעברית ומותאם לטלפון ולמחשב.

לחיצה על **כן** מסירה את הכפתור ומשאירה את **לא**. לחיצה על **לא**
מעבירה למסך השני. משם, לחיצה על **קדימה אל הברכה** מציגה את ברכת
יום ההולדת עם איור לב גדול.

בתחתית הברכה, **שולח לך נשיקות** פותח מסך עם תמונה במסגרת לב
ולבבות מרחפים. **שולח לך לבבות** מוביל לתמונת חצי הלב. אחרי 2.5
שניות מופיעה הודעה, ושתי שניות אחרי אישור השלמת הלב מופיעה הודעת הסיום.

## הפעלה מקומית

אין צורך בהתקנת חבילות. אפשר לפתוח את `index.html` בדפדפן, או להריץ
מתוך תיקיית הפרויקט:

```sh
python3 -m http.server 8000
```
